# 激光器控制系统 — 上位机说明

Qt 5 + QtSerialPort 编写的三路激光器控制上位机，与 STM32 下位机通过单字符 ASCII 串口指令通信。
支持手动调节、状态联锁、双曲线（设定值 / 实测值）实时折线图、自动 TRY 全段扫描（L1 → L2 → L3）。

---

## 1. 运行环境

| 项 | 要求 |
|---|---|
| Qt | 5.6 及以上（含 QtSerialPort、QtWidgets） |
| 编译器 | MSVC / MinGW，需支持 C++11 |
| 操作系统 | Windows（高 DPI 已适配） |
| 串口参数 | 115200 / 8N1 / 无流控 |
| STM32 固件 | 见 [../stm32/main.c](../stm32/main.c)，使用 ASCII `'0'~'9'` 协议 |

构建方法：用 Qt Creator 打开 [serialhelper.pro](serialhelper.pro)，qmake 后直接 Build。

## 2. 主要功能

### 2.1 三路激光器卡片
- 每路一个 `QGroupBox` 卡片，颜色编码：**L1 青、L2 橙、L3 紫**。
- 卡片内含：折线图、状态 LED、大字读数、实测值、步进按钮、模式按钮、原因提示。
- 整体暗色风格（背景 `#1a1a1a`），卡片边框、标题、读数颜色按通道区分。

### 2.2 状态可视化
- LED 圆点：**绿=就绪，黄=等待依赖，红=未就绪**。
- 状态文字 `就绪 / 等待依赖 / 未就绪` 与 LED 同步。
- 卡片底部红色斜体"原因提示"会写明为什么不能调，如：`等待 L1 输出 > 90 mA`。

### 2.3 电流读数与曲线
- 大数字 28 px 显示当前**设定值**（mA）。
- 实测值由 STM32 回报的 `输出电流=X.XXXA` 解析得来，单独以黄色显示。
- 折线图同时绘制：
  - **虚线（卡片色）= 设定值 setpoint**
  - **实线（黄色）= 实测值 measured**
  - L1 / L2 还有 90 mA 红色虚线 = **联锁阈值**
- 曲线时间窗默认 60 s，最多保留 600 个点。

### 2.4 手动调节
| 控件 | 行为 |
|---|---|
| `[−] [＋]` 步进按钮 | 按当前模式步长发指令 |
| `spinbox` 数字框 | 直接键入目标值，回车后程序自动连续发指令逼近 |
| `粗调 / 细调` 按钮 | 切换 L1 / L2 步长（粗调 ±10 mA，细调 ±1 mA）。L3 固定 ±100 mA |

被联锁挡住时，按钮 / 输入框会自动 disable。

L1 / L2 量程 0~1000 mA；L3 量程 800~10000 mA（与硬件 MCP4725 对应）。

### 2.5 优先级联锁
| 激光器 | 上位机可控条件 |
|---|---|
| L1 | L1 温度就绪 |
| L2 | L1 就绪 **且** L1 输出 > 90 mA **且** L2 温度就绪 |
| L3 | L1、L2 均就绪 **且** L2 输出 > 90 mA **且** L3 温度就绪 |

下位机也独立执行同一规则（[../stm32/main.c](../stm32/main.c) 中 `CheckLaser1/2/3Priority` 与 `UpdateLaserEnableStatus`），形成双层保险。

### 2.6 串口热插拔与自动重连
- 每秒扫一次串口列表（`serialCheckTimer`）。
- 设备拔出 → 自动关闭 + 状态复位。
- 设备恢复 → 2 秒后自动重连，重连成功后清空缓冲区并尝试激活激光器。
- 顶部 `打开串口` 按钮：连接后变绿色 `已连接`。

### 2.7 全段扫描（TRY）
点击 `全段扫描 (TRY)`，弹出参数对话框，依次执行：

| 阶段 | 范围 | 默认步长 | 默认时长 |
|---|---|---|---|
| L1 阶段 1 | 当前 → 850 mA | 10 mA | 90 s |
| L1 阶段 2 | 850 → 200 mA | 10 mA | 90 s |
| L1 阶段 3 | 200 → 98 mA（最终） | 10 mA | 90 s |
| **L2** | 当前 → **460 mA** | **10 mA** | **30 s** |
| **L3** | 当前 → **5000 mA** | **100 mA**（硬件最小） | **60 s** |

L2 步进会自动拆成 `±10` 粗调 + `±1` 细调；L3 步进按 100 mA 整数倍。
中途按按钮即可停止；联锁条件不满足会立即中止并在日志写出原因。

### 2.8 日志区
- `[INFO] / [WARN] / [ERROR] / [SEND] / [TRY] / [DEBUG]` 分类前缀，便于翻阅。
- STM32 的串口输出原文也会打印（自动 UTF-8 / GBK 解码，按 `\n` 分行合并粘包）。

## 3. 串口协议（与 STM32 对齐）

| 指令 | 作用 | DAC 增量 | 大约电流增量 |
|---|---|---|---|
| `'0'` | L1 粗调降 | −31 | −10 mA |
| `'1'` | L1 粗调升 | +31 | +10 mA |
| `'2'` | L1 细调降 | −3 | −1 mA |
| `'3'` | L1 细调升 | +3 | +1 mA |
| `'4'` | L2 粗调升 | +31 | +10 mA |
| `'5'` | L2 粗调降 | −31 | −10 mA |
| `'6'` | L2 细调升 | +3 | +1 mA |
| `'7'` | L2 细调降 | −3 | −1 mA |
| `'8'` | L3 升 | +20 | +100 mA |
| `'9'` | L3 降 | −20 | −100 mA |

下位机收到指令后回写文本，例：
```
Laser1: DAC=124, 输入电流=0.100A, 输入电压=0.250V, 输出电流=0.098A, 输出电压=0.245V
```
上位机用正则 `Laser([123])[^\n]*?输出电流\s*=\s*([0-9]+\.?[0-9]*)\s*A` 解析得到实测电流（A → mA）。

DAC 在下位机会被钳位：L1 / L2 的内部 12 位 DAC 上限为 3103；L3 的 MCP4725 上限为 1861。

## 4. 下位机硬件接线（节选自 [../stm32/main.c](../stm32/main.c)）

### 4.1 DAC（电流给定）
| 通道 | 器件 | 接口 |
|---|---|---|
| L1 | STM32 内置 DAC1 通道 1 | 12-bit, `HAL_DAC_SetValue` |
| L2 | STM32 内置 DAC1 通道 2 | 12-bit, `HAL_DAC_SetValue` |
| L3 | 外置 MCP4725 | I2C1, `MCP4725_SetVoltage(&hi2c1, val)` |

### 4.2 ADC（电压 / 电流回采）
ADC1 + DMA，CHANNELS = 4：

| 索引 | 通道含义 |
|---|---|
| `ADC_Value[0]` | L1 输出（PA0/PA1 之类，按 cubeMX 配置） |
| `ADC_Value[1]` | L2 输出 |
| `ADC_Value[2]` | L3 电压（PA6），映射 0–3.26 V → 2–3.3 V |
| `ADC_Value[3]` | L3 电流（PA7），映射 0–2.71 V → 0.8–10 A |

每次更改 DAC 后会 `UpdateADCValues()` 重启一次 DMA 并 `HAL_Delay(50/100)` 等待稳定再回采。

### 4.3 温度就绪信号（GPIO 输入）
| 引脚 | 含义 | 当前固件状态 |
|---|---|---|
| `PB13` | L1 温度就绪 | 200 ms 防抖采样 |
| `PB14` | L2 温度就绪 | 200 ms 防抖采样 |
| `PB15` | L3 温度就绪 | **已注释**，硬编码 `temp_status_prev3 = 1` |

### 4.4 使能输出信号（GPIO 输出，由优先级决定）
| 引脚 | 含义 |
|---|---|
| `PB12` | L1 enable |
| `PA15` | L2 enable |
| `PC4`  | L3 enable |

`UpdateLaserEnableStatus()` 在温度状态变化或开机时调用，把上述三路置位 / 复位。

## 5. 注意事项

### 5.1 DEBUG_MODE
[widget.h:19](widget.h#L19) 默认开启 `#define DEBUG_MODE`：
- 跳过真实串口，所有发送只走日志，便于无硬件时验证 UI / 扫描逻辑。
- 启用时所有联锁视为通过（`canControlLaser` 直接返回 true）。
- **发布前必须注释掉**，否则永远不会真正打开串口。

### 5.2 L3 步长硬件限制
STM32 的 `'8' / '9'` 指令在硬件上是固定 DAC ±20，对应约 **±100 mA**。
所以 L3 的最小步长就是 100 mA。如需更细颗粒，必须先改 [../stm32/main.c](../stm32/main.c) 的 `case '8'/'9'` 增量。

### 5.3 L3 的温度联锁
STM32 端 L3 的温度检测被注释掉，硬编码 `temp_status_prev3 = 1`（[../stm32/main.c:81](../stm32/main.c#L81)）。
上位机依赖此约定，仅按 L1 / L2 的输出判断是否允许调 L3。如果未来恢复 PB15 检测，需同步审视上位机 `canControlLaser(3)` / `blockReason(3)` 逻辑。

### 5.4 设定值 vs 实测值
- 折线虚线 = 上位机记录的 setpoint，**不一定等于硬件实际输出**。
- 折线实线 = 从 STM32 回报里解析的实测值，是硬件真实状态。
- 两条线分叉太大说明硬件没跟上（驱动饱和、温度未稳、保护触发等）。

### 5.5 90 mA 阈值
联锁规则要求"L1 输出 > 90 mA"才能调 L2，"L2 输出 > 90 mA"才能调 L3。
**注意**：上位机用 setpoint 判断，下位机用 GPIO 温度 + DAC 判断（实际上 STM32 端 90 mA 阈值并未直接体现在代码里，仅靠 enable 引脚串联）。日常使用：
- 调 L2 / L3 前，先把 L1 / L2 调到 100 mA 以上。
- 折线图上的红色虚线就是这个阈值。

### 5.6 TRY 扫描的安全
- 扫描期间手动操作仍然可发指令；建议扫描时不要再手动调。
- 串口断开会立即终止扫描。
- 联锁失效（如 L1 突然不就绪）也会立即终止扫描，不会"无人看管地往上爬"。
- L1 阶段 3 终点参数化（默认 98 mA）；L2 / L3 各自有独立的终点 / 步长 / 时长。

### 5.7 编码
- `serialhelper.pro` 已加 `/utf-8`，源文件保存时请使用 **UTF-8 (with/without BOM)**。
- STM32 的 `main.c` 注释是 GBK，如需修改请保留原编码或全文件转 UTF-8。

### 5.8 spinbox 直输的副作用
`spinbox` 直接键入目标值并回车后，程序会以"差值除以步长"次连续发送指令。
- 防抖间隔 120 ms / 路（`minSendIntervalMs`），所以差值很大时仍可能耗时数秒。
- 期间 UI 不会冻结但会快速刷指令，看到日志刷屏属正常。

### 5.9 高 DPI
已启用 `Qt::AA_EnableHighDpiScaling` + `PassThrough` 缩放策略。
如果在 4K 屏上仍偏小，可以把 `widget.ui` 的 `geometry` 改成 1920×1080 之类。

## 7. 常见问题排查

| 症状 | 可能原因 |
|---|---|
| 打开串口失败 | 端口被占用 / 选错端口 / 驱动未装 |
| 折线一直没有黄线（实测） | STM32 没回报 `输出电流=…A` 文本，或波特率不匹配 |
| 步进按钮全灰 | 未就绪或未达 90 mA 阈值，看卡片底部"原因提示" |
| TRY 一启动就停 | L1 未就绪 / 串口断开，看日志 `[TRY]` 行 |
| L3 调不上去 | L2 setpoint 未超 90 mA，或 L3 已到上限 10000 mA |
| 收到的中文是乱码 | STM32 输出非 UTF-8 / GBK，或被半行截断（程序已做合并，可忽略偶发） |
| 程序连接后仍显示 `打开串口` | 端口被其它进程持有，看任务管理器 |
| 编译时找不到 QtSerialPort | `pro` 文件没加 `QT += serialport` 或 Qt 安装时未勾选该模块 |
